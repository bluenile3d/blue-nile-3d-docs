# Style Thief

Style Thief transfers the colour character of one image to another directly inside Blender. Use a photograph, texture, painting, render, screenshot, HDR image, or any other colour image as a target while preserving the structure and resolution of the input.

The add-on includes eleven matching outputs, three strength presets, single-image matching, two batch directions, automatic colour-profile handling, and optional Shader Editor integration.

## Quick start

1. Install the Style Thief ZIP through **Edit → Preferences → Get Extensions → Install from Disk**.
2. Change a Blender area to the **Image Editor**, open its sidebar with ++n++, and select the **Style Thief** tab.
3. Leave **Processing Mode** set to **Single**.
4. Choose the image to recolour under **Source Image** and the look you want to borrow under **Target Image**.
5. Begin with **Method: MK Ultra**, **Strength: Adaptive**, and both colour profiles set to **Auto**.
6. Click **Steal That Style!**.

The result keeps the source image's dimensions and appears in the Image Editor. Use **All Modes** when you want Style Thief to create every method for visual comparison.
