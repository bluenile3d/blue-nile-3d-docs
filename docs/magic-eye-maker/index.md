# Magic Eye Maker

Magic Eye Maker creates autostereograms—single patterned images containing a hidden three-dimensional form—from Blender scene depth.

The active camera and scene geometry define the hidden form. Choose a procedural pattern or use your own images for the visible surface, then generate a still image or animation sequence.

## Quick start

1. Install the Magic Eye Maker ZIP through **Edit → Preferences → Get Extensions → Install from Disk**.
2. Open a scene with an active camera and visible geometry.
3. Set the resolution in Blender's **Output Properties**.
4. Open **3D Viewport → Sidebar → Magic Eye** and choose an **Output Folder**.
5. Open **Depth Map / Viewport**, click **Fit Mist Range**, and begin with **Mist Falloff: Linear** and **Depth Gamma: 1**.
6. Click **Preview** to quickly render pattern and depth preview images, then click **Generate** to create the final stereogram.

See the [User Guide](user-guide.md) for the complete controls.
