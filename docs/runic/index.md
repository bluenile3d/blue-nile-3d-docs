# RUNIC

RUNIC creates editable runes, symbols, lettering, and decorative marks directly in Blender. It uses Geometry Nodes for the generated result, so the original path or object can remain adjustable while you develop the design.

Use RUNIC to place symbols along curves and mesh edges, at individual points, across selected mesh faces, or directly on a mesh surface. It also includes a bundled font library, prepared phrase sets where available, font importing, and tools for turning hand-drawn symbols into reusable personal libraries.

## Quick start

1. Install the RUNIC ZIP in Blender using **Edit → Preferences → Get Extensions → Install from Disk**.
2. Select a mesh object and choose a preset such as **Line**, **Circle**, **Arch**, or **Single Rune** from the RUNIC panel.
3. Choose a font with **Browse Fonts**.
4. Select **Random**, **Text**, **Symbols**, or **Phrase** when the selected font provides a phrase set.
5. Adjust placement and appearance in the RUNIC panels.

The original path or object remains editable. See the [User Guide](user-guide.md) for the full workflow.
